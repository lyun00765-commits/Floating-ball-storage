## 1.1 导入与回滚

## 1.3 造测试样本

**在酒馆主页面控制台执行**（不是 iframe 里）。

```js
// ① 造一个「应该被收纳」的悬浮球
window.__mkBall = (n = 1, opts = {}) => {
  for (let i = 1; i <= n; i++) {
    const d = document.createElement('div')
    d.id = 'test-ball-' + Date.now() + '-' + i
    d.className = 'test-floating-ball'
    d.style.cssText =
      `position:fixed;right:${20 + i * 60}px;bottom:120px;` +
      `width:${opts.size || 48}px;height:${opts.h || 48}px;border-radius:50%;` +
      `background:#4a9eff;color:#fff;display:flex;align-items:center;` +
      `justify-content:center;cursor:pointer;z-index:9999`
    d.textContent = '球'
    document.body.appendChild(d)
  }
  console.log('已创建', n, '个测试球；现有', document.querySelectorAll('.test-floating-ball').length, '个')
}

// ② 造一个「不该被收纳」的关闭按钮（用于回归 R-01）
window.__mkCloseBtn = () => {
  const d = document.createElement('div')
  d.className = 'close-btn fa-times'
  d.style.cssText =
    'position:fixed;left:20px;top:20px;width:32px;height:32px;border-radius:50%;' +
    'background:#f66;color:#fff;display:flex;align-items:center;justify-content:center;cursor:pointer;z-index:9999'
  d.textContent = '×'
  document.body.appendChild(d)
  console.log('已创建关闭按钮（自动捕获不应收纳它）')
}

// ③ 造一个不会动的干扰元素（对照）
window.__mkDecoy = () => {
  const d = document.createElement('div')
  d.style.cssText = 'width:200px;height:40px;background:#888;margin:8px'
  d.textContent = '普通元素'
  document.body.appendChild(d)
}

// ④ 清理全部测试元素
window.__cleanBalls = () => {
  document.querySelectorAll('.test-floating-ball,.close-btn,.decoy').forEach(e => e.remove())
  console.log('已清理')
}
```

**为什么这些球能被识别**：`position:fixed`(+2) + `border-radius:50%` 圆形(+2) + `cursor:pointer`(+1) = 5 分，超过阈值 4；尺寸 48×48 在 20–120 内，宽高比 1 在 0.6–1.7 内。

# 第三部分：单项用例

格式：**前置** → **步骤** → **预期** → **判失败**。
凡标注 `[回归]` 的是已修缺陷的守护用例，务必优先执行。

## F1 启动与生命周期

### F1-01 冷启动
**前置**：清空页面，未加载本脚本。
**步骤**：刷新酒馆页面。
**预期**：
- 控制台出现 `[集成控件] 移动端检测: …`、`读取的脚本变量: …`、`解析后的设置: …`
- 面板贴边标签出现（默认在顶部）
- **无任何红色报错**
**判失败**：任意红色报错；或标签不出现。

### F1-02 重复加载的幂等性
**前置**：脚本已在运行。
**步骤**：在酒馆里禁用脚本再启用（或重载脚本）。
**预期**：
- 旧实例被清理（日志含「清理旧运行时」等），新实例正常
- 页面上**只有一套**面板与入口按钮（用 1.2② 的 DOM 命令核对：`[data-edge-panel-owner]` 节点数量不翻倍）
**判失败**：出现两套标签/按钮；或球在每次重载后翻倍。

### F1-03 脚本删除后清理 `[回归 R-02]`
**前置**：已收纳若干球，入口按钮可见。
**步骤**：在酒馆里**删除/禁用**本脚本，刷新。
**预期**：
- 面板、贴边标签**全部消失**
- 输入框旁入口按钮**消失**
- 已收纳的球**回到页面**（脚本不在了，不该继续霸占它们）
**判失败**：入口按钮残留（会一直占着输入框区域，用户无法自行移除）。

### F1-04 点选模式的产物不影响存活判定 `[回归 R-05]`
**前置**：正常工作状态，已收纳若干球。
**步骤**：进入点选模式（点准星），随便点一处页面。
**预期**：
- 只发生「捕获成功/未捕获」两种结果之一
- **面板、已收纳的球、入口按钮全部保持原样**
**判失败**：球逃逸 + 入口消失（说明整体 cleanup 被误触发）。

## F2 面板基础

### F2-01 标签展开面板
**步骤**：点击页面边缘的贴边标签。
**预期**：面板展开，显示已收纳球列表（无球时显示空状态）。展开时标签应有视觉反馈。
**判失败**：闪烁、展开后立即收起、面板位置错位。

### F2-02 收起面板
**步骤**：再次点击标签；或点击面板外空白处。
**预期**：面板收起，页面其它区域点击不受影响。
**判失败**：面板收不起来；或收起后页面某块区域点不动（残留透明遮罩）。

### F2-03 四向贴边
**步骤**：设置 → 位置，依次选 `左 → 右 → 上 → 下`。
**预期**：
- 面板移到对应边缘，**横向/纵向排列随之切换**（左右=纵向排列；上下=横向排列）
- 刷新后位置保持（持久化生效）
**判失败**：位置不生效；刷新后回默认；方向切换后球排列方向与贴边方向不匹配。

### F2-04 默认位置
**前置**：全新环境（清空脚本变量，或首次导入）。
**步骤**：加载脚本。
**预期**：位置为**顶部**，日志显示 `使用默认位置: top`。
**判失败**：位置为空导致面板不显示。

## F3 分页

### F3-01 每页容量
**前置**：贴边为顶部（水平布局）。
**步骤**：用 `__mkBall(3)` 造 3 个球，等自动收纳；或手动点选收纳。
**预期**：一页放 3 个，`‹` `›` 两个箭头**都禁用**。
**判失败**：3 个就分了 2 页；或箭头状态不对。

### F3-02 自动开新页
**步骤**：再收纳第 4 个球。
**预期**：出现第 2 页（3+1），`›` 变为可用，`‹` 仍禁用。
**判失败**：第 4 个球挤进第 1 页；或第 2 页为空。

### F3-03 翻页
**步骤**：点 `›` 翻到第 2 页；再点 `‹` 翻回。
**预期**：每次切换后**只有当前页可见**（1.2② 的 `可见` 列只有一行为 `true`），球的数量与顺序不变。
**判失败**：多页同时可见；翻页后球丢失或重复。

### F3-04 越界保护
**步骤**：在第 1 页连点 `‹` 数次；在最后一页连点 `›` 数次。
**预期**：页码不变，无报错。
**判失败**：页码跑到 0 或超出；或页面变空白。

### F3-05 删除后补位
**前置**：4 个球，两页（3+1）。
**步骤**：释放第 1 页里的一个球。
**预期**：**总页数变 1**，剩下 3 个球在一页里；`‹` `›` 都禁用。
**判失败**：出现空白页；或球数对不上。

### F3-06 切换贴边方向后重新分页 `[回归 R-06]`
**前置**：4 个球，2 页（3+1）。
**步骤**：位置 顶部 → 右侧 → 顶部，每次切换后都检查分页。
**预期**：**每一次都是 2 页（3+1）**。
**判失败**：切换后变成 1 页 4 个（旧缺陷：只改排列方向不重新分页）。

### F3-07 方向的容量一致性
**前置**：7 个球。
**步骤**：依次切到四个方向，每次记录页数与每页数量。
**预期**：四个方向一致，均为 3 页（3+3+1）。
**判失败**：某方向页数不同（说明两个方向的每页容量被改得不一致）。

## F4 自动捕获

### F4-01 开启自动模式
**步骤**：设置 → 自动。
**预期**：提示「已切换到自动模式：悬浮球将自动收纳」；已存在的悬浮球被收进面板。
**判失败**：开关切了但没反应；或球没被收纳。

### F4-02 收纳动态出现的球
**前置**：自动模式开启。
**步骤**：执行 `__mkBall(1)`（或打开一个会生成悬浮球的弹窗）。
**预期**：新球在数秒内被自动收纳。
**判失败**：超过约 15 秒仍未收纳。

### F4-03 关闭自动模式
**步骤**：切到手动模式；再 `__mkBall(1)`。
**预期**：新球**保持原样**，不被收纳。
**判失败**：仍在收纳（说明扫描没停）。

### F4-04 释放记忆生效 `[P0]`
**前置**：自动模式开启。
**步骤**：
1. `__mkBall(1)` → 等它被自动收纳
2. 用释放模式把它释放
3. 等 15 秒以上
**预期**：**它不会被再次自动收纳**（释放记忆生效）。
**判失败**：球被反复收进去又放出来（循环）。这条失败会导致页面持续抖动，属 P0。

### F4-05 清空释放记忆
**前置**：上一条中已释放过一个球。
**步骤**：设置 → 清空释放记忆。
**预期**：提示已清空的条数；此后该球**又能**被自动收纳。
**判失败**：清空后仍不收；或计数与实际不符。

### F4-06 不误收关闭按钮 `[回归 R-01]`
**前置**：自动模式开启。
**步骤**：执行 `__mkCloseBtn()`（一个 `.close-btn.fa-times` 元素）。
**预期**：**不被收纳**（留在页面上）。
**判失败**：关闭按钮被收进面板（旧缺陷：自动扫描缺少关闭按钮排除）。

### F4-07 不误收非悬浮元素
**步骤**：执行 `__mkDecoy()`（普通 div），并用 1.2② 观察。
**预期**：不被收纳。
**判失败**：普通元素被收纳。

## F5 手动捕获（点选模式）

### F5-01 进入点选模式
**步骤**：点准星按钮。
**预期**：
- 出现半透明遮罩（`#capture-mode-overlay`）与顶部提示「点击要捕获的悬浮球，按 ESC 或右键取消」
- 面板收起
- **页面其余部分仍可见但不可交互**（点击被遮罩拦截）
**判失败**：无遮罩；或遮罩不透明挡住页面（无法判断点哪儿）。

### F5-02 点选捕获
**前置**：页面上有一个未被收纳的球。
**步骤**：点选模式下点击它。
**预期**：提示「已捕获: xxx」；遮罩消失；球进入面板。
**判失败**：提示成功但球没进面板；或遮罩不消失。

### F5-03 点选空白处
**步骤**：点选模式下点击页面空白处。
**预期**：提示「请点击一个悬浮元素」；**遮罩消失**；**脚本继续正常工作**（面板/球/入口都在）。
**判失败**：遮罩残留（页面从此点不动）；或球逃逸 + 入口消失 `[回归 R-05]`。

### F5-04 ESC 取消
**步骤**：进入点选模式后按 `ESC`。
**预期**：遮罩消失，脚本正常工作。
**判失败**：遮罩残留；或状态失效。

### F5-05 右键取消
**步骤**：进入点选模式后点右键。
**预期**：同 F5-04；且**不弹出浏览器右键菜单**。
**判失败**：右键菜单弹出；或遮罩残留。

### F5-06 取消后不残留遮罩 `[回归 R-03]`
**步骤**：连续做 3 次「进入点选 → 取消」，中间不做其它操作。
**预期**：每次都能干净取消；结束后 `document.querySelectorAll('#capture-mode-overlay').length === 0`。
**判失败**：出现多个遮罩；或有一个点不掉（旧缺陷：toastr 抛错中断了遮罩清理）。

### F5-07 长按全部捕获
**步骤**：长按准星按钮约 1 秒。
**预期**：提示收纳了若干球；面板中的球数增加。
**判失败**：无反应；或长按后**又触发了单次点选**（说明长按与点击的抑制逻辑失效——正确行为是长按后 800ms 内的点击被忽略）。

## F6 释放与还原

### F6-01 进入释放模式
**步骤**：点手型按钮。
**预期**：面板收起（便于点击页面上的球）；提示进入释放模式；页面上的球可被点击释放。
**判失败**：面板不收起（挡住球）；或点击球无效。

### F6-02 单球释放
**步骤**：释放模式下点击面板里的一个球（或页面上的球）。
**预期**：提示「已释放悬浮球: xxx」；球**回到页面原位置**；面板中数量减 1。
**判失败**：球消失而非还原；或面板计数不更新。

### F6-03 长按全部释放
**步骤**：长按手型按钮约 1 秒。
**预期**：全部球被释放回页面，面板清空。
**判失败**：部分释放；或释放后页面出现多个重叠的球。

### F6-04 反复收纳/还原同一球（大小稳定性）`[回归 R-04]`
**步骤**：对**同一个球**执行 3–5 次「收纳 → 还原」。
**预期**：球的大小**每次都一样**。
**判失败**：球越缩越小（旧缺陷：`transform` 的 scale 被反复叠加）。

### F6-05 释放后退出释放模式
**步骤**：释放模式中点击页面空白处。
**预期**：退出释放模式，恢复普通状态（面板可正常展开）。
**判失败**：一直处于释放模式，正常点击被吞掉。

## F7 持久化

### F7-01 设置持久化
**步骤**：把位置改成「右」、模式改成「自动」→ 刷新页面。
**预期**：刷新后仍是「右」+「自动」；日志显示解析后的设置。
**判失败**：回默认值（顶部 + 手动）。

### F7-02 已收纳球持久化
**步骤**：收纳 3 个球 → 刷新。
**预期**：3 个球**仍在面板里**，且顺序与大小正常。
**判失败**：球丢失；或变成游离在页面上（「逃逸」）。

### F7-03 释放记忆持久化
**步骤**：释放 1 个球 → 刷新 → 等其恢复出现（若该脚本会重建）→ 观察是否被自动收纳。
**预期**：若自动模式开启，**不会被重新收纳**。
**判失败**：刷新后又被收进去。

**判失败**：脚本崩溃、面板不出现。

# 第四部分：联动测试

单项都过不代表组合没问题。以下每组都要**连续执行**，中途不刷新。

## L1 捕获 → 持久化 → 重启

**步骤**
1. 自动模式，`__mkBall(4)`，等全部收纳
2. 释放其中 1 个（记住是哪个）
3. 刷新页面

**预期**
- 剩 3 个球仍在面板，顺序与大小正常，分页正确（1 页 3 个）
- 被释放的那个**回到页面**（不是消失）
- 若该球会被宿主重建，则**不会被自动重新收纳**（释放记忆生效）

**判失败**：球数对不上；释放的球消失；被释放的球又被收进去。

## L2 模式切换 ↔ 扫描启停 ↔ 释放记忆

**步骤**
1. 自动模式 → 手动模式 → 再切回自动
2. 每次切换后 `__mkBall(1)`
3. 释放其中一个，观察 15 秒以上

**预期**
- 自动模式：新球被收
- 手动模式：新球不动
- 切回自动：又能收
- 释放过的球不反复被收（无「收进去又放出来」的循环）

**判失败**：切到手动后仍在扫描（后台定时器没停）；或释放后进入循环（P0）。

## L3 位置切换 → 分页 → 面板几何

**步骤**
1. 造 7 个球并全部收纳（应为 3 页 3+3+1）
2. 依次切四个方向，每次检查：分页、面板是否完整贴边、是否遮挡输入框
3. 切回起始方向

**预期**：四个方向的页数都是 3 页（3+3+1）；面板始终贴边且不遮挡输入框。

**判失败**：某方向页数不同或球溢出面板；面板压住输入框（点不到输入框）。

## L4 入口按钮 ↔ 面板状态

**步骤**
1. 用贴边标签展开面板，再用入口按钮点一次
2. 反过来：用入口按钮展开，用标签点一次
3. 释放模式下点入口按钮

**预期**：两种入口**共享同一份面板状态**，不会出现「一个说开着、一个说关着」；释放模式下点入口按钮应能正常切换面板。

**判失败**：状态不同步；或释放模式下按钮失效。

## L5 点选模式与释放模式的互斥

**步骤**
1. 进入释放模式 → 点准星进入点选模式
2. 进入点选模式 → 点手型进入释放模式

**预期**：两者互斥，后进入的会关掉先进入的；不会出现「两个遮罩同时存在」或「点击行为混乱」。

**判失败**：两个模式同时生效（点一下既捕获又释放）。

## L6 长按与点击的抑制关系

**步骤**
1. 长按准星 → 松开后**立即**再点一次准星
2. 长按手型 → 松开后立即再点一次

**预期**：长按触发「全部操作」后，**紧接着的这次点击不触发单次操作**（实现里是 800ms 内忽略点击）。

**判失败**：长按后又弹出了点选遮罩 / 又切换了释放模式。

## L7 面板展开状态下的自动捕获

**步骤**
1. 展开面板
2. `__mkBall(2)`，等自动收纳

**预期**：面板**实时更新**列表（日志会出现 `[EdgePanel] capturedBallsList 更新`）；分页随之调整；展开状态不受影响。

**判失败**：面板列表不刷新（要收起再展开才看到）；或展开状态被重置。

## L8 主题切换时的面板状态

**步骤**
1. 展开面板，回收纳若干球
2. 切换明/暗主题

**预期**：面板配色更新，**但展开状态、球列表、当前页码都不受影响**。

**判失败**：切主题后面板收起；或球列表丢失；或页码回到第 1 页。

## 严重程度怎么定

| 级别 | 判断标准 | 例子 |
|---|---|---|
| **P0** | 功能不可用、数据丢失、页面被卡住无法自行恢复 | 球逃逸 + 入口消失（R-05）；遮罩残留点不动（R-03）；释放记忆失效导致球反复收放 |

## 偶发问题的处理

偶发（比如「3 次里出 1 次」）**不要靠反复重试去确认**，那样只会丢失现场。应当：
1. 记录当前已复现的次数与失败次数（如 1/3）
2. 尽可能描述「出问题时和不出问题时有什么不同」（球数？位置？刚做过什么操作？）
3. 在控制台里加监控后再试：

```js
// 监控面板挂载点是否被移除（对应 R-05 一类问题）
new MutationObserver(rs => rs.forEach(r =>
  r.removedNodes.forEach(n => {
    if (n.nodeType === 1) console.warn('[监控] 节点被移除:', n.tagName, n.id,
      'script_id=', n.getAttribute && n.getAttribute('script_id'))
  })
)).observe(document.body, { childList: true, subtree: true })
```
