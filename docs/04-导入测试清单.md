# 导入测试清单

产物：`build/script.json`（`npm run build` 生成）

## 导入前必读

**`id` 与原脚本一致**（`5abe7f92-e52e-477f-b657-4b58fea6682d`），导入后会**替换**原脚本而非新增一个。
导入前建议先把当前能用的脚本导出留一份备份。

## 本次重构相对原版的**行为变更**

绝大部分代码是纯粹的搬运（15 份等价性规格 + token 级比对证明函数体未变），
但下面这几处是**有意改动**，测试时请重点确认：

| 编号 | 变更 | 预期效果 |
|---|---|---|
| A1 | 自动扫描新增「关闭按钮」排除 | `.close-btn` / `fa-times` 这类元素**不再**被自动收纳（原先会被误收） |
| A3 | `composeTransform` 纯缩放矩阵改为替换 | 同一个球**反复收纳/拖拽**，大小保持稳定（原先会越来越小） |
| A2 | 输入框入口接入主运行时销毁流程 | 删除/重载脚本后，输入框旁的小按钮**不再残留** |
| A4 | `toastr` 调用改走安全封装 | 宿主未提供 toastr 时不再抛错（原先会让捕获遮罩卡死） |

## 测试清单

### 一、启动

- [ ] 脚本加载无报错（控制台无红色错误）
- [ ] 面板出现在页面边缘，样式正常（圆角、毛玻璃、图标）
- [ ] 面板贴边位置正确（左/右）

### 二、面板

- [ ] 点面板图标能展开/收起
- [ ] 已收纳球列表能渲染，分页翻页正常
- [ ] 设置项能改（自动捕获开关、位置等），改完刷新后**仍然生效**
- [ ] 主题跟随父页面明暗切换

### 三、自动捕获

- [ ] 打开自动捕获后，页面上已有的悬浮球被收进面板
- [ ] 新出现的悬浮球（如打开某个弹窗后）能被自动收纳
- [ ] **聊天时（AI 流式输出）页面不卡顿**——扫描已排除 `#chat` 区域
- [ ] 关掉自动捕获后不再收纳

### 四、手动捕获

- [ ] 进入点选模式，出现半透明遮罩与提示
- [ ] 点击悬浮球 → 成功收纳，并弹出提示
- [ ] 点击空白处 → 提示「请点击一个悬浮元素」
- [ ] ESC 或右键**能取消**（遮罩消失、页面恢复可点击）
- [ ] 取消后页面**不会残留遮罩**（若残留说明 A4 修复有问题）

### 五、收纳与还原

- [ ] 收纳后的球在面板里能正常显示（图标、名称）
- [ ] 点球能还原到原位置
- [ ] **同一个球反复收纳/还原 3–5 次，大小保持稳定**（验证 A3）
- [ ] 拖拽球调整顺序正常

### 六、持久化

- [ ] 收纳若干球后刷新页面 → 球仍在面板里
- [ ] 释放（删除）某个球后刷新 → 不再出现

### 七、输入框入口

- [ ] 输入框旁出现小按钮
- [ ] 点击按钮能开/关面板
- [ ] 长按或右键能切换入口模式
- [ ] **禁用/删除脚本后，小按钮消失**（验证 A2）

### 八、多脚本共存（可选）

- [ ] 同时运行其它酒馆助手脚本，互不干扰
- [ ] 本脚本的面板不会收纳**其它脚本**的悬浮球（`script_id` 判定）

## 出问题怎么报

记录三样东西即可定位：

1. 控制台的完整报错（尤其 `[集成控件]` / `[EdgePanel]` / `[输入框入口]` 前缀的）
2. 复现步骤
3. 出问题的元素在不在 iframe 里、是不是动态插入的

## 已知的有意保留

- `klona` 仍从 CDN 加载（`testingcf.jsdelivr.net`）——这是**原有设计**，重构未改；
  若该 CDN 不可达，持久化相关功能会失效
- 含旋转的 `transform` 在收纳时仍会拼接（A3 只修了纯缩放/平移的常见情形）
- `store.js` 里「点击球挪回原位」那段把 Vue 对象当 DOM 元素用，原代码就无法工作
  （异常被 `try/catch` 吞掉）——**搬运时保持原样未修**，如果这个功能本来就没生效，属预期
